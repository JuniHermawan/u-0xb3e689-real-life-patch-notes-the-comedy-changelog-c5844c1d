## The entry

`main.py` (Python 3.13 standard library only, deterministic) writes one line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), with a gate self-check (1–160 characters, single line, non-whitespace, valid UTF-8, no trailing whitespace, read-back byte check):

> v4.0.9: fixed a bug where the brain saved the wifi password but forgot the birthday of its own mother.

## Run it

```sh
python3 -S main.py
# writes 102 chars to /output/entry.txt (or $MAKEFUN_OUTPUT_DIR/entry.txt)
```
